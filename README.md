# AI Sharing Pages

Public website repository for selected AI Sharing topics.

## Languages

The site is published in three languages:

- Simplified Chinese: `/`
- Traditional Chinese: `/zh-tw/`

Each page contains a language switcher plus canonical and `hreflang` metadata.
